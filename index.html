DB Explorer

Open a SQLite database

Everything stays on this computer. The database is read in place (however big it is) and opened read-only, so nothing you do here can change it.

In Finder, select the file and press ⌥⌘C to copy its path, then paste it here.

DB Explorer needs its small helper program running. Start it from Terminal with python3 dbexplorer.py and it will open this page for you.
